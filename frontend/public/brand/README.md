# Фирменные материалы (A46)

Графика взята с официального сайта **https://uniprom.pro/** (SVG inline в шапке
сайта) и хранится здесь без внешних ссылок.

## Файлы

| Файл | Что это | Где используется |
| --- | --- | --- |
| **`logo.svg`** | знак «У», градиентный, `viewBox="0 -0.2 19.4 25.2"` | плитка в сайдбаре (`variant="mark"`) |
| **`logo-lockup.svg`** | знак + надпись «Унипром» тёмным цветом `#0B1220` | страница входа (`variant="lockup"`) |
| **`logo-lockup-on-dark.svg`** | знак + белая надпись — как на сайте | тёмные поверхности; сейчас не подключён, готов для футера |

Подключение: `frontend/src/brand.ts` → константа `BRAND`, компонент
`frontend/src/components/BrandMark.tsx`. Файлы лежат в `public/`, поэтому
подключаются по путям `/brand/logo.svg`, `/brand/logo-lockup.svg`,
`/brand/logo-lockup-on-dark.svg`.

`BrandMark` один раз проверяет загрузку файла и кеширует результат. Если файл
не подложен или не загрузился, показывается текстовый знак `У` на фирменной
подложке — интерфейс остаётся работоспособным.

## Важно про цвет надписи

В исходнике с сайта надпись залита белым: логотип рассчитан на тёмную шапку.
Панель сайдбара и карточка входа в CRM — белые, поэтому для них используется
`logo-lockup.svg` с тёмной надписью. Пропорции, начертание и градиент знака во
всех файлах совпадают с оригиналом; изменена только заливка надписи.

## Остальные материалы паспорта

Палитра, шрифт и набор компонентов заданы кодом:

| Токен | Значение |
| --- | --- |
| Основной синий | `#1189f4` |
| Синий при наведении | `#0445fb` |
| Градиент знака | `#1BC4ED` → `#1189F4` → `#0445FB` |
| Текст | `#242424` |
| Поверхности | `#ffffff`, `#f7f7f7` |
| Шрифт | Manrope |

Значения продублированы в двух местах — при правке паспорта менять нужно оба:

- `frontend/src/brand.ts` — источник истины для приложения;
- `frontend/src/styles.css`, блок `:root` — переменные CSS.

Подменять логотип произвольной графикой нельзя: проверка A46 требует именно
официальный знак.
